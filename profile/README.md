## 📌 소개

대학생들에게 흩어져 있는 장학금·공모전 정보를 한 곳에서 큐레이션하고,
사용자 조건(학교 / 거주지역 / 학점 / 관심분야 등)에 맞춰 자동으로 매칭해주는 모바일 웹 서비스입니다.
